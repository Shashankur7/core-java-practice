# Java Practice

A collection of Java programs written while learning core Java concepts.

## Topics

- Data Types, Variables, and Operators
- Control Flow and Loops
- Methods and Constructors
- Arrays and Recursion
- Object-Oriented Programming
- Patterns and Number Programs
- Assignments and practice exercises

## Run a program

Compile and run a Java file from its own folder:

```bash
javac FileName.java
java FileName
```

Compiled `.class` files are intentionally ignored by Git; only source code is tracked.
